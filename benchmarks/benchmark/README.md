# Module benchmarks:benchmark

Measures how long each fixture change takes, with JMH.

## Usage

```bash
./gradlew :benchmarks:benchmark:run
```

See [Timing](../../docs/PERFORMANCE.md#timing) for running one fixture, the measured phases, and the profilers.
