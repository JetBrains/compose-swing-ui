# Module benchmarks:benchmark-utils

The shared harness of the benchmark suites. It drives the composable fixtures of the library modules on a composed tree and on a raw Swing tree, and measures what each change costs.

## Usage

The `memoryTest` suite runs the fixtures of every library module. See [`docs/PERFORMANCE.md`](../../docs/PERFORMANCE.md) for running the suites.
