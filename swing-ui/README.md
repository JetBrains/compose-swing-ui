# Module swing-ui

Umbrella dependency for Compose Swing UI. Brings together the core runtime, the Swing widget catalog, foundation layout, animation, and SVG rendering in a single dependency.

## Usage

Add `:swing-ui` to your dependencies to get all Compose Swing UI modules:

- [`:swing-ui-core`](../swing-ui-core/README.md) — composition runtime, `setContent`, windowing, layout, and generic modifiers.
- [`:swing-ui-components`](../swing-ui-components/README.md) — `@Composable` wrappers over Swing widgets and widget-specific modifiers.
- [`:swing-ui-foundation`](../swing-ui-foundation/README.md) — Foundation Canvas and constraint-based layout.
- [`:swing-ui-animation`](../swing-ui-animation/README.md) — containers that animate a composable in, out and between states.
- [`:swing-ui-animation-core`](../swing-ui-animation-core/README.md) — the animation engine for Compose Swing UI.
- [`:swing-ui-svg`](../swing-ui-svg/README.md) — static and animated SVG images and Swing icons.

See [Compose Swing UI](../README.md) for the project overview and quick start.
