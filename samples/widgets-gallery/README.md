# widgets-gallery sample

A runnable showcase of Compose Swing UI whose sidebar lists its sections. It also demonstrates a composable menu bar via `JMenuBar.setContent` and a custom Swing component hosted with `SwingNode`.

## Run

```bash
./gradlew :samples:widgets-gallery:run
```
